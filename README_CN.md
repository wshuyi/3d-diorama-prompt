# 3D 卡通微缩场景提示词

将任意图片转换为精美的 3D 卡通微缩场景风格。

## 使用环境

本提示词设计用于 **[Google Antigravity](https://antigravity.google/)**。

**推荐配置：**

- 模型：**Claude Opus 4.5**
- 图像生成：**Nano Banana Pro**（Claude 会自动调用）

## 使用方法

1. 打开 Google Antigravity
2. 选择 Claude Opus 4.5 作为模型
3. 上传原始图片
4. 使用 [prompt.md](prompt.md) 中的提示词

## 风格规格

| 项目 | 规格 |
| ------ | ------ |
| 渲染风格 | Cinema 4D / Blender |
| 场景类型 | 微缩立体透视模型 (Diorama) |
| 视角 | 45° 等距俯视 |
| 建模 | 圆润平滑，柔和倒角 |
| 材质 | PBR（哑光/光泽/金属/织物） |
| 灯光 | 柔和顶侧光 + 温暖环境光 |
| 阴影 | 柔软接触阴影 |
| 底座 | 圆形/方形木质展示底座 |
| 氛围 | 温馨、治愈、童话 |

## 核心原则

- **传入原图** — 让 AI 直接看图，而非读文字描述
- **只描述风格** — 提示词中不要描述图片内容
- **保持原样** — 明确要求保持原图中的所有特征
