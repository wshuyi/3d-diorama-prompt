# 3D Cartoon Diorama Prompt

[中文说明](README_CN.md)

Transform any image into a beautiful 3D cartoon miniature diorama style.

## Environment

This prompt is designed for use in **[Google Antigravity](https://antigravity.google/)**.

**Recommended Setup:**
- Model: **Claude Opus 4.5**
- Image Generation: **Nano Banana Pro** (automatically invoked by Claude)

## Usage

1. Open Google Antigravity
2. Select Claude Opus 4.5 as your model
3. Upload your source image
4. Use the prompt from [prompt.md](prompt.md)

## Style Specifications

| Item | Specification |
|------|---------------|
| Render Style | Cinema 4D / Blender |
| Scene Type | Miniature Diorama |
| View Angle | 45° Isometric |
| Modeling | Smooth, rounded edges |
| Materials | PBR (matte/glossy/metallic/fabric) |
| Lighting | Soft top-side light + warm ambient |
| Shadows | Soft contact shadows |
| Base | Round/square wooden display base |
| Mood | Cozy, healing, fairy-tale |

## Key Principles

- **Pass the original image** - Let AI see the image directly
- **Describe style only** - Don't describe content in the prompt
- **Preserve features** - Explicitly request keeping original characteristics
